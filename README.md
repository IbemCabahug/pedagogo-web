# Pedagogo Desk 🌿

> **The Calm Web Workspace for Future Educators**

Companion desktop web application for **Pedagogo**, designed to help Education students (pre-service teachers) draft 4As lesson plans, review weekly timetables, and sync with the Pedagogo Android app without database subscription costs.

---

## ✨ Key Features

1. **4As Lesson Plan Studio:**
   - Dedicated drafting workspace for Activity, Analysis, Abstraction, and Application.
   - Interactive **Bloom's Taxonomy** action verb bank (*Remember, Understand, Apply, Analyze, Evaluate, Create*).
   - 1-Click Printable / PDF export formatted for cooperating teachers (CTs).
2. **Weekly Curriculum & Observation Grid:**
   - Visual 7-day timetable with filters for *Lectures*, *Field Study (FS)*, *Demo Teaching*, and *Lesson Prep*.
3. **Peer-to-Peer QR Scan-to-Sync:**
   - Zero-database-cost transfer from mobile to web via WebRTC DataChannel.
   - Offline fallback via drag-and-drop backup files.
4. **Calm Aesthetic:**
   - Earthy Sage & Soft Parchment palette reducing eye strain during late-night study sessions.
   - Timeless Teacher's Spark daily wisdom.

## 🚀 Running Locally

# Install dependencies
